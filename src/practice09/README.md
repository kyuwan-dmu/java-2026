# Practice 09 — 사은품 지급 이벤트 (ArrayList + HashMap + HashSet)

## 상황
쇼핑몰 마케팅팀에서 긴급 요청이 왔습니다.

> "오늘 들어온 주문 중에 일정 금액 이상 구매한 고객한테 사은품을 보내야 해요.
> 주문마다 사은품을 추가해서 보여주고, 배송할 지역 목록도 뽑아주세요.
> 지역이 겹치는 주문이 많을 텐데, 중복 빼고 정리해주세요!"

## 사은품 규칙
| 주문 금액 | 사은품 |
|----------|--------|
| 20,000원 이상 | 미니 향수 세트 |
| 10,000원 이상 ~ 20,000원 미만 | 샘플 키트 |
| 10,000원 미만 | 대상 아님 |

## 요구사항
1. 주문 데이터를 순회하면서 사은품 대상 주문을 골라내시오
2. 각 대상 주문에 어떤 사은품을 줄지 결정하여 기록하시오
3. 사은품을 배송할 지역 목록을 중복 없이 정리하시오
4. 아래 결과를 출력하시오
   - 사은품 대상 주문 수 / 전체 주문 수
   - 사은품 종류별 건수
   - 대상 주문 목록 (주문번호, 상품 정보, 사은품 종류)
   - 사은품 배송 지역 목록

**`ArrayList`, `HashMap`, `HashSet`을 모두 활용해 보세요.**
